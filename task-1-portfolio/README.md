# Task 1: Personal Developer Portfolio & Project Showcase

Create a responsive developer portfolio containing a header, hero, about section, skills grid, featured projects, and contact links.

Open `index.html` directly, or serve this folder with `python -m http.server 8080`. Deploy with Firebase Hosting by using this folder as the public directory. Include dark/light themes, mobile navigation, smooth scrolling, and project modal popups.

## Suggested Stack

HTML5, CSS3 or Tailwind CSS, JavaScript ES6+, and Firebase Hosting.
