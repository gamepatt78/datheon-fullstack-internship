# Full Stack Web Development Internship

This repository contains the four tasks for the Full Stack Web Development internship.

## Tasks

1. [Personal Developer Portfolio & Project Showcase](task-1-personal-developer-portfolio)
2. [Dynamic Task Manager & Productivity Tracker](task-2-dynamic-task-manager)
3. [Real-Time Weather Forecast & Climate Telemetry App](task-3-weather-forecast-app)
4. [E-Commerce Product Catalog & Interactive Shopping Cart](task-4-e-commerce-product-catalog)

### Task 1: Personal Developer Portfolio & Project Showcase

Build a responsive, modern developer portfolio with semantic HTML, a responsive layout, dark/light theme switching, smooth scrolling, a mobile menu, project modals, and deployment to Firebase Hosting or another static host.

### Task 2: Dynamic Task Manager & Productivity Tracker

Build a responsive task manager with complete CRUD operations, categories, due dates, completion status, filters, search or drag-and-drop ordering, animations, and localStorage persistence.

### Task 3: Real-Time Weather Forecast & Climate Telemetry App

Build a responsive weather dashboard that searches cities through a weather API, shows current conditions and a five-day forecast, handles loading and error states, and changes the visual theme according to conditions.

### Task 4: E-Commerce Product Catalog & Interactive Shopping Cart

Build a storefront using the FakeStoreAPI with product search, category filters, product ratings, a persistent cart drawer, quantity controls, tax and shipping calculations, checkout, and order confirmation.
